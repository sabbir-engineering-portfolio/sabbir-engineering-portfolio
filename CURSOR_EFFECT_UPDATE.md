# Version 2.3 — Professional Cursor Effects

Added a restrained desktop-only interaction system designed for a corporate engineering portfolio:

- Smooth blue halo that eases behind the mouse pointer
- Very soft page spotlight following cursor movement
- Orange-accent response over links, buttons and cards
- Magnetic movement on primary buttons, navigation CTA and filters
- Subtle 3D tilt on product, case-study, skill and experience cards
- Cursor-position reflective sheen on interactive cards
- Automatic disablement for touch devices
- Automatic disablement for users who prefer reduced motion
- Native cursor is preserved for usability and accessibility

The effect intentionally avoids gaming-style trails, particles, rainbow effects and heavy glow.
