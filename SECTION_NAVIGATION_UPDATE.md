# Section Navigation Update

Journal has been removed from the navigation architecture.

The portfolio now behaves like a section-based single-page application:
- Clicking Home, About, Experience, Work, Manuals, Training, Skills or Contact shows only that view.
- Other portfolio sections are hidden, so scrolling cannot accidentally move into another navigation section.
- Long sections can still scroll internally as normal page content.
- URL hashes still work (for example `#work`) and browser back/forward navigation remains usable.
- Work includes the Product Lifecycle block.
- About includes Education.
